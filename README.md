# 📚 LLM Course Recommender

An LLM-powered course recommendation system that matches user resumes to relevant online courses using semantic search.

## 🔍 Features
- Resume parsing & preprocessing
- Sentence embeddings for semantic similarity
- FAISS-based vector search
- Course ranking & recommendations
- Extensible to RAG / LLM explanations

## 🧠 Tech Stack
- Python
- SentenceTransformers
- FAISS
- Pandas / NumPy
- (Optional) OpenAI / Gemini for explanations
